# План програмного застосунку

## 1. Призначення

Програмний застосунок є інтерфейсом для демонстрації інтелектуальної системи
прогнозування добових енергетичних витрат користувача фітнес-трекера.

Застосунок має використовувати підготовлену модель машинного навчання та
показувати результат прогнозування разом із основною інформацією про
вхідні дані, часову історію та результати роботи моделі.

---

## 2. Основний сценарій роботи

1. Користувач обирає користувача фітнес-трекера.
2. Обирає дату, для якої необхідно сформувати прогноз.
3. Система отримує доступні дані за попередні дні.
4. Формуються необхідні часові ознаки.
5. Підготовлена модель формує прогноз Calories на наступний день.
6. Результат відображається в інтерфейсі.
7. Користувач може переглянути історію фактичних та прогнозованих значень.

---

## 3. Основний екран

На основному екрані передбачається відображення:

- вибору користувача;
- дати прогнозування;
- кнопки формування прогнозу;
- прогнозованого значення Calories;
- використаної моделі;
- основних показників останньої активності;
- графіка фактичних та прогнозованих значень.
