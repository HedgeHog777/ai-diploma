# 🧠 FitnessML Master Thesis

Machine Learning project developed as part of a Master's degree thesis.

## Project Overview

This repository contains the implementation of a complete machine learning pipeline for analyzing and forecasting physiological and behavioral parameters collected from fitness tracker users.

The project is being developed as a Master's diploma project and includes:

- dataset analysis and validation;
- exploratory data analysis (EDA);
- data preprocessing;
- feature engineering;
- classical machine learning models;
- neural network experiments;
- model evaluation and comparison;
- explainable AI techniques (SHAP, Feature Importance);
- preparation of tables, figures and materials for the final thesis.
